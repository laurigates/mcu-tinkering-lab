# MG90D — Micro Metal Gear Servo, Double Ball Bearing

**Manufacturer:** TowerPro
**Used in:** Not used. Candidate SG90 replacement for the robocar pan/tilt head;
fits the same 9 g bracket going by its case dimensions. See
[servo selection](../servo-selection.md).

TowerPro publishes no PDF datasheet for this part. Everything below is from the
TowerPro product page, read 2026-09-15. TowerPro describes it as an "upgrade
version of TowerPro MG90s".

Not to be confused with the **MG90D Robot servo 360° Rotation**, a separate
TowerPro product that rotates continuously and cannot hold a position.

## Key Specs

| Parameter | Value |
|-----------|-------|
| Size class | Micro (TowerPro category "Mini Servo 11-20g") |
| Modulation | **Digital** ("MG90D New Digital 13g Metal gear, double ball bearing servo") |
| Weight | 13 g |
| Dimensions | 22.8 × 12.2 × 28.5 mm |
| Stall torque | 2.1 kg/cm (4.8 V); 2.4 kg/cm (6.6 V) |
| Speed | 0.10 s/60° (4.8 V); 0.08 s/60° (6.0 V) |
| Voltage | 4.8–6.6 V |
| Dead band | 1 µs |
| Gears | Metal; aluminium 6061-T6 gear set and shaft |
| Case | Alloy middle section |
| Bearing | Double ball bearing |
| Temperature | 0–55 °C |
| Connector | JR (fits JR and Futaba), 25 cm lead |
| PWM frame rate | **Not stated** |
| Pulse range | **Not stated** |
