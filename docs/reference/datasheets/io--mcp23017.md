# MCP23017 — 16-Bit I/O Expander with I2C Interface

**Manufacturer:** Microchip Technology
**Used in:** robocar-unified, optional GPIO expansion on TCA9548A channel 2
(`I2C_BUS_CHANNEL_MCP23017`, `MCP23017_ADDR` in `packages/robocar/unified/main/pin_config.h`).
The fitted breakout is described in [`cjmcu-2317.md`](../boards/cjmcu-2317.md).

Every value below was read from Microchip's datasheet DS20001952**D** (Revision D,
June 2022). Page numbers are the PDF's own `DS20001952D-page N` footers. The
MCP23S17 is the same die with an SPI port. The datasheet covers both, and the
CJMCU-2317's silkscreen prints both sets of names (`SDA/SI`, `NC/CS`).

## I2C Address

The 7-bit address is `0100 A2 A1 A0`: 0x20 with all three pins low, 0x27
with all three high (p. 15 §3.3.1, Figure 3-4).

- A0, A1, A2 **must be externally biased**. The datasheet gives no internal
  default (p. 11 Table 2-1, p. 15 §3.3).
- On the MCP23017 the address pins are always enabled. `IOCON.HAEN` only
  affects the MCP23S17 (p. 21 Register 3-5, Note 1).

`MCP23017_ADDR 0x20` in `pin_config.h` is correct only if the board holds all
three pins low. See the open check in [`cjmcu-2317.md`](../boards/cjmcu-2317.md).

| Pin | Name | Pin | Name |
|-----|------|-----|------|
| 1–8 | GPB0–GPB7 | 15 | A0 |
| 9 | VDD | 16 | A1 |
| 10 | VSS | 17 | A2 |
| 11 | NC (MCP23S17: CS) | 18 | RESET (active low) |
| 12 | SCL (MCP23S17: SCK) | 19 | INTB |
| 13 | SDA (MCP23S17: SI) | 20 | INTA |
| 14 | NC (MCP23S17: SO) | 21–28 | GPA0–GPA7 |

## RESET

- Hardware reset that **must be externally biased** (p. 11 Table 2-1).
- Minimum low pulse is 1 µs, and outputs go high-impedance within 1 µs of RESET going low
  (p. 5 Table 1-2, params 30 and 34).
- An internal POR also resets the part. It needs a VDD rise of at least
  0.05 V/ms, a figure marked "design guidance only" (p. 4 D003, p. 12 §3.1).

## Registers the firmware relies on

Addresses are given for `IOCON.BANK = 0`, the power-on default (p. 12, p. 16 Table 3-3).

| Register | Addr | POR value | Notes |
|----------|------|-----------|-------|
| IODIRA / IODIRB | 0x00 / 0x01 | 0xFF | 1 = input. The note on p. 18 §3.5.1 reads: "For MCP23017, IO7 must be set via I2C interface to '0' (output)." |
| GPPUA / GPPUB | 0x0C / 0x0D | 0x00 | 100 kΩ pull-ups, which act only on inputs (p. 22) |
| IOCON | 0x0A (also 0x0B) | 0x00 | BANK, MIRROR, SEQOP, DISSLW, HAEN, ODR, INTPOL (p. 21 Register 3-5) |
| GPIOA / GPIOB | 0x12 / 0x13 | 0x00 | A read returns the pins. A write goes to OLAT (p. 16 §3.4) |
| OLATA / OLATB | 0x14 / 0x15 | 0x00 | Output latches (p. 24 §3.5.11) |

- Sequential mode is the default (`SEQOP = 0`), so the address pointer
  increments after each byte. This lets the driver read both IODIR bytes in one
  transfer (p. 13 §3.2.1, p. 21).
- INTA follows PORTA and INTB follows PORTB unless `IOCON.MIRROR = 1`. Each
  pin can be active-high, active-low or open-drain (p. 11 Table 2-1, p. 21,
  p. 24 §3.6.1).

## Application notes for robocar-unified

- **Supply.** The robot runs the expander from the 3.3 V logic rail. At that
  voltage the part is rated to 400 kHz, which is the `I2C_MASTER_FREQ_HZ`
  the bus uses. 1.7 MHz needs VDD ≥ 4.5 V (p. 6). The datasheet has no 1 MHz
  (Fm+) row.
- **GPA7/GPB7.** These are pin 7 and pin 15 in the `mcp23x17` driver's
  0–15 numbering. Configure them as outputs only. They power up as inputs
  (IODIR POR = 0xFF, p. 16) until firmware clears bit 7.
- **5 V signals.** With VDD = 3.3 V no pin may exceed 3.9 V (p. 3). A 5 V
  sensor output needs a divider or level shifter.
- **Decoupling.** The datasheet names no decoupling capacitor value. The
  "100 nF" in `WIRING.md` is generic practice, not a datasheet figure.
