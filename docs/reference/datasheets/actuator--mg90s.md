# MG90S — Micro Metal Gear Servo

**Manufacturer:** TowerPro (widely counterfeited)
**Used in:** Not used. Candidate SG90 replacement for the robocar pan/tilt head;
fits the same 9 g bracket. See [servo selection](../servo-selection.md).

TowerPro publishes no PDF datasheet for this part. Everything below is from the
TowerPro product page, read 2026-09-15.

## Key Specs

| Parameter | Value |
|-----------|-------|
| Size class | Micro (TowerPro category "Mini Servo 11-20g") |
| Modulation | **Digital** ("MG90S digital servo") |
| Weight | 13.4 g |
| Dimensions | 22.8 × 12.2 × 28.5 mm |
| Stall torque | 1.8 kg/cm (4.8 V); 2.2 kg/cm (6.6 V) |
| Speed | 0.10 s/60° (4.8 V); 0.08 s/60° (6.0 V) |
| Voltage | 4.8 V (torque also quoted at 6.6 V) |
| Dead band | 1 µs |
| Gears | Aluminium 6061-T6 gear set and shaft |
| Temperature | 0–55 °C |
| Connector | JR (fits JR and Futaba), 25 cm lead |
| PWM frame rate | **Not stated** |
| Pulse range | **Not stated** |

## Mechanical

TowerPro's lettered dimensions (mm), using its dimension key:

| Letter | Meaning | Value |
|--------|---------|-------|
| A | Overall height including output spline | 32.5 |
| B | Case length | 22.8 |
| C | Case height, excluding spline | 28.4 |
| D | Case width | 12.4 |
| E | Length across mounting tabs | 32.1 |
| F | Base to underside of mounting tabs | 18.5 |

C and D differ slightly from the headline 28.5 × 12.2 mm; both figures are
TowerPro's.

## Counterfeits and analog listings

TowerPro's page warns that many MG90S servos sold on eBay, Amazon and Alibaba
are counterfeits, identifiable by the TowerPro logo being removed from photos
and descriptions. Many reseller listings describe the MG90S as analog. A part
that is not from TowerPro or an authorized dealer may not match the digital
specification above.
