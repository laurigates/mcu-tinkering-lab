# GY-521 MPU-6050 Breakout

An unbranded breakout for the TDK InvenSense MPU-6050 6-axis gyroscope and
accelerometer, with an 8-pin 2.54 mm header. The balancebot's IMU is one: it
sits in J3, a 1×8 socket on the carrier, and core 1 reads it at 500 Hz over
I2C1. For the chip see [`sensor--mpu6050.md`](../datasheets/sensor--mpu6050.md);
the MPU-6050 itself is **obsolete** at TDK (that page, § Lifecycle).

| | |

| Fitted on | balancebot carrier J3 and the perfboard prototype J3 |
| Header | 1×8, 2.54 mm; the carrier takes it in a 1×8 female socket (`docs/reference/parts/gy-521.toml`) |
| Outline | the outline 21.00 × 15.88 mm, header along the 21 mm edge: measured with calipers by Lauri on 2026-11-09. Where the holes sit in it is an estimate, not measured: the 8-hole row centred along the 21 mm edge (end holes 1.61 mm from each short edge) and the hole centres 1.27 mm in from that edge. The carrier's `Breakout_Sockets:GY521_Socket` footprint draws this outline (`tools/kicad/lib/breakout-sockets/sockets.toml`) |
| Listing | None recorded in the repo for the module itself. `gy-521.toml`'s `buy` is the female header strip, not the module |

"GY-521" is a design many makers build, not one maker's product, and no vendor
board file or schematic from a named maker exists. The schematic quoted below is
a reseller's copy (Jamtronic) of the drawing that circulates with the design;
the parts on any one module have to be read off that module.

## Pin mapping

**Viewed from the component side, with the header along the bottom edge and the
X arrow pointing up.** The order is the silkscreen read on 2026-10-14. Which end
is on the left in this view is derived from the carrier's confirmed fit, not
read directly: carrier README § "Check before ordering", item 3, has pin 1 (VCC)
at the left end of J3 with the module component side up and its X arrow towards
FWD, which is the top of the board view. Check it on the module (below).

`Side`/`Pos` follow [`tools/hardware/layout.py`](../../../tools/hardware/layout.py):
`B` is the bottom edge, `Pos 1` the left end.

| Pin | Side | Pos | Silkscreen | Chip pin (PS §7.1) | Notes |
|-----|------|-----|------------|--------------------|-------|
| VCC | B | 1 | `VCC` | — | Module supply, into the onboard LDO (schematic below). balancebot and glowbug feed 3.3 V |
| GND | B | 2 | `GND` | 18 | |
| SCL | B | 3 | `SCL` | 23 | I2C clock; pulled up on the module (value varies, below) |
| SDA | B | 4 | `SDA` | 24 | I2C data; pulled up on the module |
| XDA | B | 5 | `XDA` | 6 (AUX_DA) | Auxiliary I2C data, for a magnetometer; unused here |
| XCL | B | 6 | `XCL` | 7 (AUX_CL) | Auxiliary I2C clock; unused here |
| AD0 | B | 7 | `AD0` | 9 | Address LSB: low = 0x68, high = 0x69 (PS §6.4). Pulled down on the module per the schematic |
| INT | B | 8 | `INT` | 12 | Interrupt out; push-pull, active high at reset (RM §4.15) |

## On the module (from a reseller schematic, not this board)

The Jamtronic "MPU 6050 GY-521" document carries a schematic (listed under
References). It shows:

| Part | Schematic value | Function |
|------|-----------------|----------|
| Q2 | "3.3V LDO", 5-pin (I, GND, en, by, O), part number not given | VCC (net `VCC_5V`) in, `VCC_3.3V` out; `en` tied to the input |
| C3 | 4.7 µF | LDO input |
| C10, C12 | 10 µF, 0.1 µF | LDO output |
| R4, R5 | 4.7 kΩ | SDA and SCL pull-ups to `VCC_3.3V` |
| R6 | 4.7 kΩ | AD0 to GND |
| R201, D1 | 1 kΩ, LED | Power LED on `VCC_3.3V` |
| C11 | 0.01 µF | VLOGIC (pin 8) bypass; VLOGIC tied to `VCC_3.3V` |
| C13 | 0.1 µF | REGOUT (pin 10) |
| C14 | 2200 pF | CPOUT (pin 20) |
| C102 | 0.1 µF | VDD (pin 13), on `VCC_3.3V` |

CLKIN and FSYNC go to GND; XDA, XCL and INT go straight to the header with no
pull-ups. The capacitor values match the chip's recommended external parts
(PS §7.3: 0.1 µF REGOUT, 0.1 µF VDD, 2.2 nF CPOUT, 10 nF VLOGIC). The same
document's feature list gives "Power supply: 3-5v (internal low dropout
regulator)".

### Clone variance

- **Pull-up value.** The Jamtronic schematic shows 4.7 kΩ. The Arduino
  Playground MPU-6050 page says the GY-521's pull-ups are "sometimes 10k and
  sometimes 2k2". Read the two resistors next to the header on the module in
  hand before adding pull-ups elsewhere on the bus.
- **Capacitor quality.** The Playground page reports that "Some GY-521 modules
  have the wrong capacitor (or a bad capacitor) and that results into a high
  noise level".
- **Regulator.** The Jamtronic schematic draws a 5-pin LDO without naming it;
  no source read for this page names the part fitted to the common modules.
- **The chip.** The MPU-6050 is obsolete at TDK, so the chip on a module bought
  now is old stock or of unstated origin. The balancebot firmware refuses a part
  whose WHO_AM_I is not 0x68 (`src/mpu6050.c`).

## Power

- **The module's VCC is the LDO's input**, and every pin of the chip, the I2C
  pull-ups and VLOGIC sit on the LDO's output (Jamtronic schematic). So the
  module's I2C high level and the INT high level are the LDO's output, not VCC:
  VOH ≥ 0.9 × VLOGIC on INT (PS §6.4).
- **From 5 V:** the LDO makes 3.3 V and the I2C lines idle at 3.3 V, safe for a
  3.3 V host. The Playground page prefers this: "It is preferred to apply 5V to
  the VCC pin of the sensor board".
- **From 3.3 V (balancebot, glowbug):** the chip gets 3.3 V less the LDO's
  dropout. The chip runs from 2.375 V (PS §6.3), so this works unless the
  dropout exceeds about 0.9 V, but the fitted LDO's dropout is unknown. The
  Playground page warns that from 3.3 V "the resulting voltage (after the
  onboard voltage regulator) might be too low for a good working I2C bus": the
  pull-ups idle below 3.3 V, and the host's VIH threshold has less margin.
- **balancebot's WIRING.md disagrees with the schematic.** It says the module
  "works fed from 3V3 directly (bypassing the regulator)". The schematic has no
  bypass: VCC reaches the chip only through the LDO. Either the fitted module
  differs from the schematic or the sentence is wrong; measuring the chip's VDD
  (below) settles it. This page does not change WIRING.md.

## Address

AD0 is pulled to GND on the module (R6, 4.7 kΩ, Jamtronic schematic), so an
unconnected AD0 gives **0x68**. Tie AD0 to VLOGIC for 0x69 (PS §6.4). WHO_AM_I
reads 0x68 at either address (RM §4.34), so it confirms the chip, not the
strap.

## Known issues and quirks

- **Starts asleep.** PWR_MGMT_1 resets to 0x40 (SLEEP); a driver must clear it
  before reading (RM §3, §4.30). balancebot writes 0x01 (wake, X-gyro PLL
  clock, as RM §4.30 recommends); glowbug writes 0x00 (wake, internal 8 MHz
  oscillator).
- **Mounting.** The balancebot filter needs X forward and Z up; the delivered
  8d18cd8d carrier fits the module component side down, and the firmware's
  `mount down` setting compensates (balancebot README § IMU mounting).
- **Pull-ups stack.** A second board with pull-ups on the same bus lowers the
  total. The balancebot carrier's Qwiic tap J7 adds none for this reason
  (carrier README).

## Check on the physical board

With the module unpowered unless stated:

- [ ] **Orientation.** Component side up, header along the bottom, X arrow
      pointing up: is `VCC` at the left end?
- [ ] **Regulator.** Read the marking on the LDO and look up its dropout. Is it
      a 5-pin part as the schematic draws, or a 3-pin SOT-23?
- [ ] **Chip supply from 3.3 V.** Powered from the balancebot's 3V3, measure
      the chip's VDD (the LDO output or C102) against GND. This settles the
      WIRING.md "bypassing the regulator" sentence.
- [ ] **I2C pull-ups.** Measure SDA to the LDO output and SCL to the LDO
      output (4.7 kΩ in the schematic; 2.2 kΩ or 10 kΩ on other modules).
- [ ] **AD0.** Measure AD0 to GND (4.7 kΩ in the schematic).
- [ ] **XDA/XCL.** Confirm no pull-ups on the auxiliary pins.
- [ ] **Chip marking.** Read the marking on the QFN (`MPU-6050` and a date or
      lot code), since the part is obsolete and modules may carry old stock or
      substitutes.
- [x] **Outline.** The board measures 21.00 × 15.88 mm (Lauri, calipers,
      2026-11-09).
- [ ] **Hole positions.** Measure from each short edge to the nearest header
      hole centre (assumed 1.61 mm, the row centred), and from the long edge
      to the hole centres (assumed 1.27 mm). Correct `GY521_Socket`'s
      `outline` in `tools/kicad/lib/breakout-sockets/sockets.toml` if either
      differs.
- [ ] **Mounting holes.** Measure their diameter and centres; nothing in the
      repo uses them yet.
